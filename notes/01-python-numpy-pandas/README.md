# NumPy Week 1 Notes

## Purpose
This folder covers the first week of the study roadmap: NumPy arrays, dimensions, indexing, vectorization, broadcasting, aggregation, and numerical precision.

## Learning goals
- Understand scalar, 1D, 2D, and higher-dimensional arrays.
- Explain `shape`, `ndim`, `size`, and `dtype`.
- Perform efficient vectorized operations without manual Python loops.
- Handle slicing, fancy indexing, and boolean masks confidently.
- Understand broadcasting rules and common compatibility issues.
- Interpret reductions and summarize numerical behavior without confusion.

## Recommended order
1. `01-arrays-dtypes-shape.py`
2. `02-indexing-slicing-masks.py`
3. `03-vectorization-and-broadcasting.py`
4. `04-aggregations-and-precision.py`

## Weekly objective
A strong understanding of NumPy fundamentals is required before moving into Pandas, SQL, statistics, and machine learning workflows.
