# Data Science \& Machine Learning Engineering

**A structured journey from data analysis to machine learning systems.**

This repository documents my continuous learning in Data Science and Machine Learning Engineering through concise notes, practical exercises, experiments, and end-to-end projects.

My focus is on understanding the concepts behind the code, applying them to real-world datasets, and gradually developing the skills required to build reliable, data-driven applications.

## 🎯 Objectives

- Develop strong foundations in statistics, probability, and data analysis.
- Strengthen practical skills in Python, NumPy, Pandas, and SQL.
- Understand, train, and evaluate machine learning models.
- Practice feature engineering, model validation, and error analysis.
- Build reproducible projects and deploy models through APIs.
- Explore experiment tracking, testing, and essential MLOps practices.
- Prepare a technical portfolio for future opportunities and graduate studies.

## 📈 Learning Principles

1. Understand the concept before relying on a library.
2. Practice independently before checking solutions.
3. Use appropriate evaluation methods and avoid data leakage.
4. Document assumptions, limitations, and important decisions.
5. Prioritize reproducibility, readable code, and meaningful results.
6. Learn consistently and improve through feedback.
